### 📱 Net & Notion — Professional Networking App
> `React Native` · `Expo 54` · `Firebase` · `React Navigation`
> **Published on Google Play** · Works on Android, iOS, and web

A mobile app for saving professional contacts with context — who you met, where, and what to follow up on. Generates QR codes for quick contact sharing, supports camera scanning, and handles the full contact lifecycle. Built with a team of 4.

[![Get it on Google Play](https://img.shields.io/badge/Google_Play-Download-414141?style=for-the-badge&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=com.rbdfranck.netandnotion)

### 🤖 AI Developer Tooling Suite
> `TypeScript` · `Node.js` · `Hono` · `OpenRouter` · `ChromaDB` · `Tavily` · `Zod`

A collection of AI-powered tools that automate real developer tasks:
- **img-debug** — paste a screenshot of an error, get an explanation and fix using vision AI (Google Gemini + Tavily)
- **Semantic search** — finds relevant products by meaning, not keywords, using text embeddings and Cohere reranking over 194 products
- **RAG Q&A** — answers questions about the Node.js documentation using ChromaDB vector store
- **PR Analyser** — analyses GitHub pull requests and gives structured feedback using chain-of-thought prompting
- **Job Search Assistant** — 3-phase pipeline: scrapes postings, analyses your resume against them, and flags suspicious listings via WHOIS and web search

---

### ☁️ Fragments — Cloud Microservice API
> `Node.js` · `Express` · `AWS S3` · `AWS DynamoDB` · `Docker` · `Jest` · `Passport.js`

A cloud API that lets users store, retrieve, and convert text and image data across multiple formats (plain text, Markdown, HTML, PNG, JPEG). Built with AWS S3 for file storage, DynamoDB for metadata, Docker for deployment, and JWT authentication. Tested end-to-end with Jest, Supertest, and Hurl. Includes a companion web app (Fragments UI) for managing data in the browser.

### 🍁 SettleCAN — Settlement Assistant for Newcomers to Canada
> `React` · `Vite` · `Express.js 5` · `Supabase` · `PostgreSQL` · `WebSockets` · `Vitest`

A web app helping newcomers to Canada find and track settlement resources — work permits, health services, housing checklists, and community tools. Built with a team of 5. Owned the task manager, checklist, community hub, real-time notifications, scheduled email reminders, and database schema.

### 🚗 Self-Driving Car Simulation
> `Python` · `TensorFlow` · `Keras` · `OpenCV` · `NumPy`
